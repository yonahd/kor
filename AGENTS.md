# AGENTS.md

Go CLI (cobra) that finds unused Kubernetes resources. Module: `github.com/yonahd/kor`. Go directive in `go.mod` pins a specific toolchain (`go 1.26.8`); `GOTOOLCHAIN=auto` picks it up.

## Commands

- `make build` — builds to `build/kor` (not `./kor`).
- `make lint` / `make lint-fix` — golangci-lint (v2 config, `.golangci.yaml`). `gci` enforces import grouping: stdlib, external, then `prefix(github.com/yonahd/kor)`. Put `github.com/yonahd/kor/...` imports in their own group or lint fails.
- `make test` — `go test -race -coverprofile=coverage.txt -shuffle on ./...` (randomized test order).
- Single test/package: `go test -run 'TestName' ./pkg/kor/...`
- Exception JSON helpers (require `jq`): `make sort-exception-files`, `make dedup-exception-files`. CI runs `make validate-exception-sorting` and `make validate-exception-duplications` on PRs touching `pkg/kor/exceptions/**` and will fail if run is skipped.

## Layout

- `pkg/kor/<resource>s.go` — detection logic: `GetUnusedXxxs(filterOpts, clientset, outputFormat, opts)` → string, backed by `processNamespaceXxx`. Entry points read `filterOpts.Namespaces(clientset)` for ns iteration.
- `pkg/kor/all.go` (`kor all`), `multi.go` (comma-separated resources), `delete.go`, `formatter.go` (table/json/yaml, `--group-by`).
- `cmd/kor/<resource>s.go` — cobra command wiring flags to `filters.Options` and `common.Opts`; clients are created inside `Run` via `kor.GetKubeClient` / `GetAPIExtensionsClient` / `GetDynamicClient` (`pkg/kor/kor.go`). In-cluster mode is auto-detected via `/var/run/secrets/kubernetes.io/serviceaccount/token`.
- `pkg/filters` — filter framework. Default registry has `label`, `age`, `korlabel` filters. All retrieve functions skip resources where `filter.SetObject(&obj).Run(filterOpts)` returns true (the global `filter` lives in `pkg/kor/init.go`).

## Adding a new resource type

An orphaned-resource addition touches many files; follow `CONTRIBUTING.md` "Repository Structure": detection in `pkg/kor/<r>s.go`, tests in `<r>s_test.go`, a `CreateTestXxx` helper in `pkg/kor/create_test_resources.go`, wiring in `pkg/kor/all.go`, `delete.go`, `multi.go`, a command in `cmd/kor/<r>s.go`, RBAC in `charts/kor/templates/role.yaml`, and README docs.

## Exceptions JSON

Each `pkg/kor/exceptions/<r>s/<r>s.json` is embedded via `//go:embed` and follows the `Config`/`ExceptionResource` structs in `pkg/kor/kor.go` (`Namespace`, `ResourceName`, `MatchRegex`). Files must stay sorted by `Namespace` then `ResourceName` — run `make sort-exception-files` before committing.

## Labels

- `kor/used=true` — resource is skipped (handled by the `korlabel` filter).
- `kor/used=false` — resource is force-reported as unused with reason "Marked with unused label" (handled in each `retrieve...Names` func).

## Tests

Unit tests use `k8s.io/client-go/kubernetes/fake` — no cluster or kubeconfig needed. Shared test helpers/vars (`CreateTestXxx`, `testNamespace`, `AppLabels`, `UsedLabels`, `UnusedLabels`) come from `pkg/kor/create_test_resources.go`. Note: some test files (e.g. `configmaps_test.go`) contain an `init()` that replaces `scheme.Scheme`. Slack notifier tests use `httpmock` (`pkg/utils/slack_test.go`).

## Chart changes

`charts/kor/README.md` is generated by helm-docs; CI (`helm-test.yaml`) requires it be regenerated via `docker run --rm --volume "$(pwd):/helm-docs" jnorwood/helm-docs:latest` or the PR fails. Release/tag conventions are in `RELEASE.md`.
